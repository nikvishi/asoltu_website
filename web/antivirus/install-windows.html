Download for Windows

Why does Windows show a warning? Microsoft SmartScreen warns about any new program that does not yet have a paid code-signing certificate and a download history. It does not mean the file is harmful. Check the SHA-256 fingerprint below to be sure your download is the original, untouched file.

Installation steps

  1. Download the installer and open it from your Downloads folder. If your browser says the file “isn’t commonly downloaded”, choose Keep (in Edge: … → Keep → Keep anyway).
  2. A blue window titled “Windows protected your PC” appears. Click More info.

    More info
    Don’t run

    Illustration — Windows may look slightly different.

  3. Check that App shows ASOLTU-ANTIVIRUS-Setup-1.0.0.exe, then click Run anyway.

    Windows protected your PC

    App: ASOLTU-ANTIVIRUS-Setup-1.0.0.exe

    “Unknown publisher” is expected until the app is code-signed.

  4. Accept the licence, choose a folder (the default is fine) and click Install. No administrator password is needed. ASOLTU opens when setup finishes and keeps protecting you from the tray icon (bottom-right of the taskbar).

Verify your download (recommended)

Open PowerShell (right-click Start → Terminal) and run:

Get-FileHash "$env:USERPROFILE\Downloads\ASOLTU-ANTIVIRUS-Setup-1.0.0.exe" -Algorithm SHA256

The Hash it prints must match exactly:

0D3A0FD386DB3D5BFAD41C9B16A3A3B6F314606665DBC74E425DB9B0A6D00A07

If it does not match, delete the file and download it again only from this page.

Still blocked?

  • No Run anyway button: your PC or organisation enforces SmartScreen. Ask your administrator, or right-click the file → Properties → tick Unblock → OK, then open it again.
  • “Smart App Control” blocked it (Windows 11): this mode only allows signed apps and has no bypass. Install ASOLTU on a PC without Smart App Control, or wait for the signed release.
  • Never turn off Microsoft Defender or SmartScreen to install ASOLTU — it is not required.
