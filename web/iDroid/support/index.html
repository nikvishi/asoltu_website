i2Droid — Support

Direct, phone-to-phone file transfer for iPhone and Android

Need help with i2Droid? Start with the common issues below, or reach out directly and we'll get back to you.

QR code won't scan

  • Make sure Camera permission is granted: Settings → i2Droid → Camera.
  • Hold the phone steady and keep the whole QR code inside the frame — for offline pairing codes specifically, don't zoom in, since the code is denser than a normal QR and needs the full pattern in view.
  • Good, even lighting helps a lot. Use the torch button in the scanner if it's dark.

Two devices can't connect / "waiting" forever

  • Both devices must be on the same Wi-Fi network, or one device's personal hotspot.
  • For fully offline pairing, turn off mobile data on both devices — only a shared local network (e.g. one phone's hotspot) is needed, no internet connection at all.
  • If a transfer stalls mid-way, make sure neither device's screen has locked — locking can suspend the app and pause the connection.

A received file is missing

Received photos and videos are saved to your device's regular Photos/Downloads location. Check the app's "You" or history tab for a record of past transfers.
